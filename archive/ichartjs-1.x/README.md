# iChart.js 1.x Archive

This directory contains the historical iChart.js 1.x implementation.
It is preserved for reference only and is not part of the iChart.js 2.0
runtime, build, test, or release process.

The archived source is in `src/`, documentation is in `docs/`, and the
legacy bundles, minified files, plugins, samples, tests, and build
configuration are reference material only.
