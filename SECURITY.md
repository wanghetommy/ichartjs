# Security Policy

## Supported Versions

iChart.js 2.0 is the first supported Agent-first product line. The archived 1.x code is not supported and does not share a compatibility or migration contract with 2.0.

| Version | Supported |
| --- | --- |
| 2.0 prereleases and releases | Yes |
| 1.x archive | No |

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability. Use the repository's private security advisory form:

`https://github.com/wanghetommy/ichartjs/security/advisories/new`

Include the affected version, reproduction steps, impact, and any suggested mitigation. Avoid including production data, credentials, access tokens, or other secrets.

The project will acknowledge a valid report, assess severity, and coordinate a fix and disclosure before publishing technical details.
